Stove compatibility

Compatibility depends on the firmware version of the stove's mainboard, not on the model. Each firmware generation speaks its own variant of the protocol, and the bridge finds out by itself which one your stove uses.

By firmware version

The version is shown in the Info menu of the stove screen.

Firmware 2.28 needs bridge firmware 4.0 or later for everything: versions before 3.6.1 could show "FIRENET UPDATE" or the code UW29 instead of linking, and versions before 4.0 only sent on/off, mode, power and temperature to the stove.

First start

On its first start with a stove, the bridge tries the three protocol variants in turn and keeps the one the stove answers. This takes about six seconds; afterwards it starts with the right one directly. There is nothing to configure.

On any other model, the Stove tab shows a link "My stove has MultiAir: show its settings". Use it if your stove is equipped and not in this list, and tell us so that we add it.

The board

The firmware is tested on the ESP32-S3. The board must expose the chip's native USB (USB OTG) on a connector: the stove acts as the USB host and the bridge as a USB serial device.

  • ESP32-S3 with native USB: works.
  • ESP32-S2: has native USB too and may work, untested.
  • ESP32, ESP32-C3 and boards with only a UART bridge chip: will not work.

Tell us about your stove

If your stove or firmware version is not listed, or behaves differently, open an issue with the model, the firmware version, the log (CDC Logs tab) and the output of http://open-firenet.local/api/state.
