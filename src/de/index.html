Lokale Steuerung für RIKA-Pelletöfen

Open Firenet ersetzt den RIKA Firenet Stick durch ein ESP32-S3-Board. Ihr Ofen erhält eine lokale Webseite, eine REST-API, MQTT und eine Home-Assistant-Integration. Kein Cloud-Konto, kein Internet erforderlich.

Erste Schritte Ist mein Ofen kompatibel?

Funktionen

Steuerung über Ihr Netzwerk

Ein/Aus, Betriebsart, Heizleistung, Solltemperatur, Wochen-Heizplan, Frostschutz und MultiAir-Gebläse bei Öfen, die damit ausgestattet sind.

Alles, was der Ofen meldet

Temperaturen, Pelletverbrauch, Betriebsstunden, Wartungs-Countdown, Fehler- und Warncodes: bis zu 88 Werte unter ihren RIKA-Namen.

Passt zu Ihrer Hausautomation

Eine Home-Assistant-Integration, eine REST-API und MQTT für Jeedom, openHAB, Node-RED, Domoticz und andere Systeme.

100 % lokal

Der Stick kommuniziert über USB mit dem Ofen und über WLAN mit Ihnen. Es wird nichts an einen externen Server gesendet.

Display auf dem Stick

Mit einem LilyGO T-Dongle-S3 werden Ofenstatus und Raumtemperatur direkt auf dem Display des Sticks angezeigt. Display ansehen.

Drei Komponenten

Firmware

Läuft auf dem am Ofen angeschlossenen ESP32-S3. Stellt die Webseite und die API bereit.

open-firenet auf GitHub

Installer

Desktop-App für Windows, macOS und Linux: flasht das Board, richtet WLAN ein, führt Over-the-Air-Updates durch.

Installer herunterladen

Home Assistant

Thermostat, Gebläse, Heizplan-Schalter, Sensoren und Diagnose, installiert über HACS.
