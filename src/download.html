The first time you start it

The installer is not signed with a paid publisher certificate, so your computer may warn you the first time. This is expected.

  • Windows: on the blue "Windows protected your PC" screen, click More info, then Run anyway.
  • Mac: open the .dmg file and drag Open Firenet Installer into Applications. If the Mac says the app cannot be opened, open System Settings > Privacy & Security and click Open Anyway.
  • Linux: allow the AppImage file to run as a program (in its properties, or with chmod +x), or install the .deb package. Details in the step-by-step guide.

Then follow How it works or the step-by-step guide. Older versions and the checksums are on the releases page.
